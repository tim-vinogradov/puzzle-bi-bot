# Демо-сценарий и текст выступления (≈ 7 минут)

Перед показом: запустите `start.bat`, нажмите «＋ Новый диалог». Если дашборды из репетиции мешают — удалите файл `storage/app.db` (бот создаст пустой).

## 1. Проблема (30 секунд)
«Руководителю нужен ответ здесь и сейчас. В BI-системе нужного отчёта может не быть, а заказ нового занимает дни. Мы сделали чат-бота, который по вопросу обычным языком сам находит данные, считает то, что попросили, и строит живой дашборд прямо в чате».

## 2. Запрос → уточнение → дашборд (1,5 минуты)
Напишите: **Собери дашборд по продажам: план-факт по регионам и торговым точкам**
- Бот спрашивает период — «когда данных недостаточно, бот уточняет». Нажмите **«Последние 12 месяцев»**.
- Покажите: понял запрос → SQL (раскройте, «только чтение») → **единая таблица** → дашборд.
- KPI сверху: план 1,25 млрд, факт 1,13 млрд, выполнение 90,4% красным, динамика к прошлому году +18,7% зелёным.
- Резюме внизу: «лидер — Центральный, слабее всего — Уральский».

## 3. Живой инструмент (1,5 минуты)
- Фильтр «Регион»: начните вводить **«Центр»** → Enter. «Все графики и KPI пересчитались». Откройте фильтр «Торговая точка» — «в списке только 68 точек Центрального региона: каскад».
- Наведите на столбец — точные значения, отклонение, % выполнения.
- Выделите мышью область на первом графике — «четвёртый график приблизился синхронно».
- Переключатель **Разрез → Точки**, **Период → Квартал**.
- «Сбросить фильтры».

## 4. Вычисления диалогом (1,5 минуты)
- **Добавь колонку с процентом выполнения плана** → подсвеченная колонка в таблице. «Пользователь не пишет код — формула видна словами».
- **Перестрой третий график — отсортируй по проценту выполнения**
- **Добавь динамику к предыдущему месяцу** → **Покажи четвёртый график с учётом динамики**
- (по желанию) **Посчитай факт минус план, делить на план, умножить на 100** — произвольная формула.
- «Все вычисления — на стороне бота, без повторных запросов к базе; отношения считаются из сумм, а не усредняются».

## 5. Сохранение и возврат (1 минута)
- **Сохрани дашборд под названием «Продажи Q3»**
- **Покажи мои дашборды** → поиск, сортировка, переименовать, копия, удалить.
- Обновите страницу в браузере (F5) — «черновик и переписка на месте».
- **Открой дашборд «Продажи Q3»** — «восстановились таблица, вычисления, графики, фильтры, KPI».
- **Скачай дашборд в HTML** — интерактивный отчёт; «Скачать ▾ → Картинка PNG».

## 6. Другие вопросы (30 секунд, если есть время)
- **Сравни продажи по торговым точкам за год, выдели отстающих** — рейтинг худших, точечная диаграмма «план против факта» по всем 296 точкам, тепловая карта.
- **Покажи по клиенту Х за последние 3 года, какие скидки делались и почему** — бот не нашёл клиента «Х» и предлагает выбрать.
- Вопросы голосом руководителя (эффектно в конце): **Какой регион лучший?** → **Кто отстаёт?** → **А за прошлый год?** → **Сравни с прошлым годом**. «Бот помнит, о чём разговор, и отвечает числом, а не только графиком».

## 7. Безопасность и архитектура (30 секунд)
«База — только на чтение: отдельная роль, read-only транзакции, каждый SQL проверяется анализатором — один SELECT, только разрешённые таблицы, лимит строк и таймаут. Формулы — без исполнения кода. Понимание — встроенные правила русского языка плюс, по желанию, GigaChat или любая OpenAI-совместимая модель: модель возвращает только JSON-действия, которые проверяются. 93 автотеста, работает на PostgreSQL и встроенной SQLite».

## Запасные ответы на вопросы жюри
- **Почему не только LLM?** Типовые запросы должны работать мгновенно, бесплатно и одинаково каждый раз. Модель подключается для свободных формулировок и нестандартных вопросов (пишет SELECT, который проверяется).
- **Как перенести на Oracle из реального ТЗ?** Диалектозависимых мест два: усечение даты до месяца и параметры — вынесены в `semantic._month_expr`; sqlglot умеет диалект Oracle.
- **Сколько данных выдержит?** Годовая таблица — 34 тыс. строк, отрисовка дашборда ≈ 0,3–0,5 с. Лимит строк и таймауты настраиваются в `.env`.
- **Можно ли в корпоративный мессенджер?** Логика отделена от интерфейса: `/api/chat` принимает текст и возвращает блоки; дашборд-ссылку `/share/…` можно отправить в любой мессенджер.
